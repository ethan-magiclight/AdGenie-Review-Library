## 1. 设计目标

- 首页第一要务是传递**高级质感**——AdGenie 卖的是品牌广告，首页本身就是第一条"品牌广告"
- 核心交互隐喻：**电视机**。品牌广告的行业词是 TVC（Television Commercial），复古 CRT 电视是产品的核心视觉符号——"让你的商品，登上电视广告级的质感"
- 参考：布局结构参考 Higgsfield 首页（卡片轮播 + 输入框），主色调参考 Higgsfield SEEDANCE 2.0 视觉（近黑底 + 荧光黄绿 + 粗压缩标题字）

## 2. 核心概念

| 产品概念 | UI 隐喻 |
|---|---|
| 商品品类（用户的第一入口） | 品类 Tabs——"你在哪个电视台" |
| 视频题材（10 个） | **电视机边框上的实体频道按钮**——"电视上的频道" |
| 模板视频 | 电视屏幕里正在播出的广告 |
| 切换题材 | 换台，带短暂 CRT 换台动效（≤0.3s，克制） |

用户心智：小 B 用户只关心自己品类的效果，因此**品类是一级状态**，切换品类后电视播放内容与模板墙全部更换；每个品类下包含全部题材（案例不足的题材行直接隐藏，不显示空态）。

## 3. 页面结构（自上而下）

```
导航:    AdGenie logo · 模板库 · 我的商品(P3 预留) · CTA
Hero:    标题「让你的商品，拍出大牌广告感」+ 副标
品类Tabs: [耳机数码] [香水] [美妆护肤] [口红彩妆] [运动鞋服] [腕表配饰] [美发电器] [箱包]
电视舞台: ╭─────────────────╮
         │  当前品类×题材     │ ○ TVC大片     ← 题材=边框实体按钮
         │  精选视频自动轮播   │ ○ 产品特写       激活按钮荧光绿点亮
         ╰─────────────────╯ ○ 美学B-Roll
                              ○ 开箱 · UGC ···
输入框:   [ 粘贴产品链接 / 上传商品图 → 自动推荐模板 ]   ← 电视机正下方
模板墙:   当前品类下按题材分行，行内横滑
         TVC品牌大片  [卡片][卡片][卡片] →
         产品特写     [卡片][卡片][卡片] →
         …
```

## 4. 关键交互

1. **品类 Tabs**：一级状态。切换 → 电视内容 + 题材按钮高亮 + 模板墙整体更换
2. **题材按钮**：做成立体按压式频道键质感；点击 → 电视 0.3s 换台闪烁 → 播放该题材精选
3. **电视屏幕**：当前（品类×题材）精选案例自动循环播放，hover 显示暂停/静音控制
4. **输入框**：一种输入框两种输入——粘贴产品链接自动解析，或拖入商品图。Demo 阶段提交后做假交互（跳转推荐结果占位页）
5. **模板卡片**：封面 + 模板名 + 时长 + 题材标签；hover 播放视频预览

## 6. 视觉基调

- **底色**：近黑 #0A0A0B 级别
- **强调色**：荧光黄绿（约 #C6FF3A），极度克制——只用于：激活的题材按钮、标题强调字、CTA、当前品类 Tab
- **字体**：中文标题用思源黑体 Heavy 收紧字距；英文点缀词（TVC、B-Roll 等行业词保留英文）用 Archivo Black / Anton 类压缩粗体
- **CRT 电视**：深色磨砂边框、屏幕微曲面反光、极淡扫描线；不做蒸汽波风格，保持高级克制
- 界面语言：**中文为主**，行业词保留英文点缀
