# AdGenie Review Library

AdGenie 品牌广告样片采集、分类、审核和状态标记工作台。

当前项目把商品品类、广告题材、样片库、审核状态和方法论沉淀放在一个本地可启动的平台里，方便团队逐条审核 YouTube 品宣广告视频，并记录：

- 商品品类 × 题材覆盖情况；
- 视频是否待审核、需复刻、已复刻、暂搁置、已入库、已排除、已拉黑；
- 分类纠错、拉黑原因和方法论候选线索；
- 缺发布时间 / 时长 metadata 的视频，避免使用“看起来很老”这类不可审计原因。

## 快速启动

```bash
cd web
npm run import
npm run dev
```

默认访问：

```text
http://127.0.0.1:4173
```

## 部署前检查

```bash
cd web
npm run build
```

当前项目是 Node 静态服务 + JSON 状态文件，不需要前端打包产物。`npm run build` 在这里作为健康门禁，会执行语法检查和数据校验。

## 主要目录

| 路径 | 作用 |
|---|---|
| `web/` | 审核平台：前端、Node API、状态数据和维护脚本 |
| `collect/` | 采集方法论、题材定义、消费电子分类和样片事实源 |
| `docs/` | 需求表和产品规划文档 |
| `PROJECT_HEALTH.md` | 当前健康状态、风险和下一步建议 |

## 数据注意事项

- 当前运行状态保存在 `web/data/creative-library-state.json`。
- `npm run reset:data` 会重新生成状态文件，可能覆盖人工标记；正式使用前务必先 `npm run backup:data`。
- 本仓库默认不提交本地下载的视频、抽帧图片和历史输出目录，平台会优先使用 YouTube 在线预览和缩略图。

## 当前定位

- 单人本地审核：可用。
- 小团队内网共享：可试用，建议固定一台主机并定期备份。
- 公网多人长期部署：建议先升级到 SQLite / Postgres，并补登录鉴权、并发写入保护和自动备份。
