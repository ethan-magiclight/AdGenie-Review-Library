### 规则变更流程

1. 记录触发规则变化的具体案例和原判断错误。
2. 判断它属于来源、内容性质、题材、年代、AI 价值还是去重计数问题。
3. 修改唯一事实源，不在多个 Markdown、Excel 和脚本中分别手改。
4. 将案例加入回归表；可以自动执行的判断同时进入校验脚本或阻止列表。
5. 对受影响的数据全量重审，而不是只对已发现的视频 ID 打补丁。
6. 生成新版本工作簿并记录规则版本、重审范围和未完成项。

## 2. 分类目标

### 题材分类追求成熟心智，不追求理论互斥

题材名称的价值在于：行业、用户、内容团队和检索平台已经对某种广告内容形成稳定、可理解的认知。判断标准是：

- 品牌、代理商、案例库、创作者和用户是否反复使用相近名称。
- 内容团队看到标签、定义和边界后，能否知道该生产什么。
- 能否据此形成有效检索词，并稳定判断搜索结果是否匹配。
- 产品用户能否按商品品类和题材筛选模板，而不需要先理解抽象传播理论。

因此一条视频可以多标签。多标签不是为了增加覆盖率，而是承认成熟内容形态可能复合存在。

### 主题材与次题材

- 内部审核先确定 1 个主题材：最能代表观看预期和内容骨架的标签。
- 次题材只有在视频中存在独立、连续、可指认的画面证据时才成立。
- 标题、搜索词、播放列表名称和单个画面瞬间不能直接成为标签。
- 当前工作簿可以继续只展示多标签，不新增用户未要求的字段；主题材用于内部审核和冲突裁决。

正式 29 题材、定义、成立证据、排除边界、检索语义和 TopView 映射统一见 `ad-video-genres-v1.json`。

## 3. 七道审核门

每道门解决不同问题，不能用前一道的结果替代后一道。

### Gate 1：搜索召回

目标是尽量发现候选，不做最终分类。

查询模板：

```text
{品牌} {商品品类} {题材检索语义} site:youtube.com
{品牌} {产品型号} official commercial site:youtube.com
{品牌} {战役名} campaign film site:youtube.com
```

- `official how to`、`official features video` 等查询只说明候选从哪条检索路径被召回。
- `discovery_matches.target_genre` 只能保存在召回证据中，禁止直接复制为正式 `genres`。
- 稀缺真人题材可从专业创作者和垂类账号召回，但来源必须如实记录。

### Gate 2：链接、发布者与母片真实性

- URL 必须来自真实公开结果，禁止构造。
- 确认可播放、标题与内容一致，并能够继续审片。
- 分开记录品牌主频道、品牌地区频道、品牌支持频道、制作方、媒体和创作者。
- 同一实质母片的地区上传、语言版、字幕版和长度剪辑建立同一 `canonical_master_id`，选择最完整、最清晰、来源最直接的代表版本。

来源优先级不等于模板资格：品牌官方只能证明发布者关系，不能证明内容是广告。

### Gate 3：内容性质

先回答“它是什么内容”，再判断题材：

| 内容性质 | 核心模板默认处理 |
|---|---|
| 品牌商业广告 / 产品品宣片 | 继续审核 |
| 广告化产品介绍 | 继续审核 |
| 品牌支持教程 / Quick Start / 排错 | 默认进入支持内容参考，不进入品牌品宣核心模板；存在明确广告化成片证据时人工例外 |
| 完整发布会 / 直播回放 | 排除 |
| 独立媒体测评 / 创作者长测评 | 排除品牌品宣核心模板 |
| 幕后花絮 / 拆机 / 制作纪录 | 排除 |
| 品牌纪录片 / 人物纪录片 | 默认只进灵感库 |

审核问题：

1. 视频是在建立购买欲和品牌/产品价值，还是在解决已经购买用户的操作问题？
2. 是否存在广告化钩子、利益表达、产品欲望和品牌收束？
3. 去掉品牌频道身份后，内容本身仍会被行业用户识别为品宣广告吗？

以下内容不得因为“官方、最新、竖屏或有播放量”获得质量加分：普通社媒日常、低制作投流素材、单场景轻剧情、产品弱露出的生活片段。画幅只用于渠道覆盖统计，不能替代广告属性和制作质量判断。

### Gate 4：年代、产品代际与视觉语言

核心模板以当前产品表达为标准，不仅看视频发布日期：

| 年代 | 处理 |
|---|---|
| 近 3 年 | 优先；仍需通过其他审核门 |
| 3–5 年 | 产品仍在售或表达仍具代表性、画面不过时才接受 |
| 超过 5 年 | 默认进入历史 / 灵感参考库，不计普通 MVP 核心模板覆盖 |
| 经典例外 | 需人工说明不可替代价值，不计入普通的每格 10 条供给 |

出现过时产品代际、低清画面、旧字幕样式、旧画幅或明显过时制作语言时，即使未满 5 年也可排除。

### Gate 5：题材独立分类

必须综合实际画面、字幕和元数据，按 `ad-video-genres-v1.json` 独立分类：

1. 写出主题材及对应时间段 / 代表帧。
2. 对每个次题材写出独立证据。
3. 对最容易混淆的相邻题材说明排除理由。
4. 无足够证据时标为待复核，不继承搜索题材。

高频边界：

- `Feature Callout`：卖点、参数、利益点、功能图标或视觉标注。
- `How-To Tutorial`：有顺序的连接、设置、佩戴、操作或排错步骤。
- 操作步骤文字不能因为“有字幕”就重复标为 `Feature Callout`。
- `Product Demo` 回答功能如何工作；`How-To` 回答用户按什么顺序完成任务。
- `Unboxing` 必须有包装从关闭到打开、取出产品与配件的真实连续过程。
- `Daily Routine` 必须有紧凑、可复制的连续生活流程；一个生活镜头或人物纪录片慢铺垫不成立。

### Gate 6：AI 可生成性与生成价值

这两项分别判断：

- `AI 可生成性`：现有模型和制作链路能否较稳定地生成主要镜头。
- `AI 生成价值`：即使能生成，把它做成模板是否能给用户带来明显创意和制作收益。

核心模板至少满足：

- 至少 3 个独立、可描述、可生成的视觉段落。
- 镜头具备场景、构图、运动、材质、光影、动态图形或产品交互中的至少两类发挥空间。
- 产品、使用动作、结果或卖点是画面主体，静音后仍能理解主要内容。
- 不是以白底手动操作、屏幕录制、静态步骤页、单一固定机位或同一人物口播为主体。
- 模板结构可以迁移到同品类的其他商品，而不是依赖特定名人、真实人生、历史事件或不可复现现场。

推荐量化检查：

- 均匀抽取 10 帧，并补充场景切换帧。
- 同一人物正面讲话达到 6/10 帧，默认判为口播主导。
- 产品、使用、功效或卖点相关视觉少于 3/10 帧，默认产品主体不足。
- 前 5 秒没有产品、痛点、利益或视觉钩子时，需要人工说明为什么仍有模板价值。
- `frames_reviewed = 10` 只表示取得 10 帧；必须另有视觉判断和证据，不能把帧数当成审核完成。

### Gate 7：核心模板资格与计数

进入 MVP 核心模板库必须同时满足：

- 链接和来源可核验。
- 内容性质是品牌商业广告、产品品宣或经人工批准的广告化内容。
- 年代与产品代际符合核心库要求。
- 至少一个正式题材有实际画面证据。
- AI 可生成性和 AI 生成价值均通过。
- 时长为 16–119 秒；16–17 秒仍需检查信息密度，120 秒及以上直接排除。
- 不是重复母片。

计数键：

```text
商品品类 + 题材 + canonical_master_id
```

同一母片可以贡献多个真正成立的题材，但在同一格只计一次。每格目标 10 条不构成降低质量门槛的理由。

## 4. 10 点 Storyboard 审核要求

`bradautomates/claude-video` 可用于建立证据链，但不能代替判断：

1. 读取公开标题、发布者、时长和发布日期。
2. 获取字幕；字幕缺失时以画面为主。
3. 在 0%、10%……90% 采帧，并补充重要场景切换。
4. 审核者必须真正查看画面并记录内容性质、题材证据、口播占比、产品主体和 AI 价值。
5. 不能稳定加载足够帧时标记待复核，不提前入库。

建议内部 review 数据分别保存：

```json
{
  "publisher_role": "brand_support_channel",
  "content_nature": "support_tutorial",
  "primary_genre": "How-To Tutorial",
  "secondary_genres": [],
  "recency_status": "over_5_years",
  "ai_generatable": true,
  "ai_generation_value": "low",
  "core_template_eligible": false,
  "decision_reason_codes": ["SUPPORT_CONTENT", "LOW_AI_CREATIVE_HEADROOM"]
}
```

这些是内部审核字段，不代表本轮向 Excel 新增展示字段。

## 5. 直接排除规则

任一项命中即不进入普通 MVP 核心模板：

| 代码 | 规则 |
|---|---|
| `DURATION_OUT_OF_RANGE` | ≤15 秒或 ≥120 秒；16–17 秒内容单薄也排除 |
| `SUPPORT_CONTENT` | 支持教程、Quick Start、安装设置或排错内容，且缺少广告化品宣表达 |
| `EVENT_OR_LAUNCH` | 完整发布会、直播回放或以舞台演讲为主体 |
| `BEHIND_THE_SCENES` | 幕后、制作花絮、拍摄纪录 |
| `DOCUMENTARY_STYLE` | 人物背景、真实经历或日常环境慢铺垫，产品弱露出 |
| `TALKING_HEAD_DOMINANT` | 同一人物正面讲话主导，视觉变化和产品段落不足 |
| `PRODUCT_NOT_VISUAL_SUBJECT` | 无法回答卖什么、为什么买，或产品相关视觉少于 3/10 帧 |
| `OUTDATED_PRODUCT_OR_VISUALS` | 超过 5 年且无经典例外，或产品代际、画面语言明显过时 |
| `LOW_AI_CREATIVE_HEADROOM` | 以白底手动操作、录屏、静态步骤页为主，缺乏可生成视觉段落 |
| `SOURCE_NOT_VERIFIED` | 链接、发布者或内容无法核验 |
| `DUPLICATE_MASTER` | 同一实质母片已有代表版本 |
| `SOCIAL_FILLER` | 普通社媒日常或账号填充内容，缺少明确商业传播命题和品牌广告结构 |
| `LOW_QUALITY_PERFORMANCE_AD` | 低制作投流素材，虽有销售目的但不具备品牌样片质量和可复刻价值 |
| `NOT_BRAND_ADVERTISING` | 去掉发布账号身份后，内容本身不能被识别为品牌广告 |
| `PET_CUTE_CONTENT_ONLY` | 宠物用品行业：只有萌宠、搞笑、陪伴或日常素材，缺少商品主张、产品证明和品牌收束 |
| `ANIMAL_WELFARE_RISK` | 宠物用品行业：画面存在明显不安全、不舒适、强迫宠物配合或可能误导的使用方式 |
| `UNVERIFIED_HEALTH_CLAIM` | 宠物用品行业：健康、医疗、营养功效表达过强，无法在广告语境内合理核验 |
| `RESCUE_DOCUMENTARY_STYLE` | 宠物用品行业：救助、领养、公益纪录片风格，不适合作为商品广告模板 |
| `VET_EDUCATION_CONTENT` | 宠物用品行业：兽医/专家长科普或教育内容，不是品牌品宣广告 |
| `RETAIL_LISTING_VIDEO` | 宠物用品行业：电商货架、Top list、详情页式低质素材，缺少品牌广告结构和复刻价值 |

宠物用品新增采集硬规则：

- 标题或描述中出现 `:15`、`15s`、`15 sec`、`15-second`、`00:15` 等明确 15 秒版本标记时，即使平台返回时长为 16 秒，也按 `DURATION_OUT_OF_RANGE` 排除；这是 YouTube/yt-dlp 对 15 秒广告四舍五入造成的常见漏网。
- 宠物智能用品中 `Getting Started`、`How to Clean`、`How to Assemble`、`Setup Guide`、`Quick Start`、配件升级包、替换滤芯/托盘等内容默认属于支持/维护/配件说明，不因官方账号和产品匹配进入品牌品宣候选。
- 标题含 `Meet`、`Introducing`、`Get to know` 的智能宠物用品视频只能进入候选；是否为 `Product Demo` / `Feature Callout` / `TVC` 必须靠抽帧判断广告结构、宠物使用关系和品牌收束。

## 7. 行业、消费电子与宠物用品商品分类

核心行业：

`Consumer Electronics` · `Pet Supplies` · `Skincare` · `Color Cosmetics` · `Fragrance` · `Personal Care` · `Jewelry & Watches` · `Apparel & Footwear` · `Bags & Accessories` · `Home Appliances & Living` · `Food & Beverage` · `Sports & Outdoor`

- 按广告中被销售的具体产品和主要消费用途选择 1 个主行业，不按品牌统一分类。
- `Other` 只作系统兜底，不进入核心覆盖率。
- 消费电子继续下钻 34 个商品品类，正式名称与边界见 `consumer-electronics-taxonomy-v1.json`。
- 每条消费电子样片只选择 1 个主商品品类；多产品或跨品类内容只作兜底，不计单品类覆盖率。
- 宠物用品继续下钻到商品心智品类，正式名称与边界见 `pet-supplies-taxonomy-v1.json`。
- 宠物用品不按“狗用品 / 猫用品”作为一级分类；适用动物是使用对象标签，一级品类以商品类型和购买心智为准。

### 宠物用品行业补充规则

宠物用品不能无脑复用消费电子的判断逻辑。消费电子常以产品本体、参数、结构和功能交互作为主要证明；宠物用品还必须把宠物使用过程、主人操作、使用结果、包装/品牌收束和明确卖点字幕一起纳入产品证据。

宠物用品品牌广告成立至少回答四个问题：

1. 卖的是什么宠物商品，而不是只出现宠物或主人？
2. 解决什么宠物或主人问题，例如挑食、异味、掉毛、清理、焦虑、运动、喂养、定位？
3. 为什么这个品牌/产品值得买，画面中是否有产品证明、结果证明或品牌主张？
4. 去掉账号身份后，内容本身仍会被行业用户识别为品牌广告，而不是萌宠日常、公益纪录或测评内容？

有效产品证据包括：

- 产品包装、颗粒、质地、材质、设备外观。
- 主人打开、喂食、清理、佩戴、安装、设置或操作产品。
- 宠物食用、玩耍、如厕、饮水、被护理、外出或与设备互动。
- 使用前后变化，例如清洁、除臭、毛发、行为、便利性或安全感。
- 明确卖点字幕、品牌收束、campaign 口号和商品利益表达。

无效证据包括：

- 宠物可爱、宠物出镜、主人陪伴本身。
- 救助、领养、公益故事中的品牌露出。
- 兽医长科普、健康知识讲解或疾病治疗内容。
- 创作者测评、Top list、Amazon finds、低质电商详情页。
- 动物明显不适、被强迫配合或存在安全风险的画面。

宠物用品核心题材第一阶段优先：

`TVC / Brand Commercial` · `Concept Film / Brand Manifesto` · `Story-Driven Product Ad` · `Problem–Solution` · `Product Demo` · `Feature Callout` · `Before & After` · `Daily Routine` · `UGC Ad` · `Testimonial / Review` · `Macro Close-Up` · `Unboxing` · `How-To Tutorial` · `Try-On / Try-Out`

宠物食品、猫砂、洗护和健康护理可以更多依赖 `Problem–Solution`、`Before & After`、`Daily Routine` 和 `Feature Callout`；智能宠物用品更接近消费电子，但仍必须检查宠物真实使用关系和动物福利风险。

2026-08-12 宠物用品试点采集认知：

- YouTube 官方账号列表可召回 Freshpet、The Farmer's Dog、Petcube、Litter-Robot、Petlibro、PetSafe 等候选，但当前环境下 YouTube RSS 和单条详情页经常返回 404 / bot 校验，导致发布时间缺失。
- 发布时间缺失的视频只能作为 `metadata_status = publish_date_missing` 的待补元数据候选；不能计入“最近发布”“优质入库”或 MVP 覆盖数。
- `--allow-pending-publish-date` 只用于扩大人工待审池，不能用于绕过年代门。正式入库仍需补发布时间或人工确认未过时。
- 当前 `build-contact-sheets.py` 默认不使用浏览器 Cookie，部分 YouTube 视频下载会触发 “Sign in to confirm you’re not a bot”。这种情况下保留 manifest 错误，不把未抽帧视频导入正式库。

## 8. 来源与检索路径

新的活动采集入口统一为 `collect-latest.mjs`。先按行业 policy 读取对应品类、Top 品牌、官方账号和规则版本，再按 `platform-source-registry-v1.json` 读取官方账号的 Shorts / Videos，并用品牌 × 产品线 × 题材搜索补漏。只有注册表中频道 ID 或已登记官方 handle 一致的结果才能自动认定为官方来源；频道显示名相似不能作为官方证明。

搜索召回前必须明确商品品类、题材范围、品牌层级、平台形态和发布时间窗口。`recall_genres` 与正式 `genres` 分字段保存；正式分类只能在 10 点抽帧之后产生。

优先顺序：

1. 品牌商业主频道及正式 Campaign / Commercial / Product Film 播放列表。
2. 明确的代理商、制作公司、导演或奖项库发布。
3. 对 UGC、Testimonial、Vox Pop 等品牌官方稀缺题材，使用可信专业创作者或垂类账号。
4. 品牌支持频道只用于发现教程心智和支持内容，不默认作为品牌品宣核心样片来源。

奖项、品牌知名度、官方认证和经典地位只证明来源或行业价值，不能替代内容性质、年代和 AI 模板审核。

## 9. 失败模式

| 失败模式 | 根因 | 修正 |
|---|---|---|
| 搜索题材直接污染正式标签 | 将召回查询当成视觉分类结果 | 搜索证据与正式标签分字段保存，正式标签必须有画面证据 |
| 获得 10 帧就当成完成审核 | `frames_reviewed` 只统计文件数量 | 保存视觉判断、时间段和理由码，并做语义回归 |
| AI 适配循环自证 | “已接受且有题材”被直接当成 AI 适配 | 独立判断可生成性、生成价值和核心模板资格 |
| 品牌官方与品牌品宣混为一谈 | 频道匹配只看品牌名 | 分开记录发布者角色和内容性质 |
| 年代偏好没有执行 | 文档写近 5 年，代码只拦 8 年以上 | 超过 5 年默认退出普通核心库，经典例外单独审批 |
| 用视频 ID 补丁代替全量审核 | 只修已发现案例 | 规则变化后对受影响集合全量重审，并保留固定回归案例 |
| 为覆盖数量硬塞样片 | 把每格 10 条当成质量要求 | 数量是供给目标，质量门是入库条件；不足保持缺口 |

## 10. 记录与验证

面向样片库的基本字段保持不变：

```json
{
  "industry": "Consumer Electronics",
  "product_category": "True Wireless / Bluetooth Earbuds",
  "brand": "Example Brand",
  "title": "Original video title",
  "url": "https://www.youtube.com/watch?v=example",
  "genres": ["Feature Callout", "Product Demo"],
  "source_type": "品牌官方",
  "note": "发布日期、产品代际和关键判断"
}
```

每轮提交前至少验证：

- 题材 JSON 可解析、数量为 29、英文标签唯一、分组合法。
- 入库脚本的合法题材与题材事实源完全一致。
- 四个回归案例符合预期。
- 正式标签与搜索召回标签没有自动继承关系。
- 所有接受样片有内容性质、年代、视觉证据、AI 价值和母片去重判断。
- 工作簿数量与重审后的 review 数据一致，但数据一致性不能代替语义正确性。

## 11. 下一步执行顺序

1. 校验品类、题材、Top 品牌、官方账号和采集策略五个事实源。
2. 运行统一采集器，选择商品品类、题材、品牌层级、平台形态和时间窗口。
3. 对全历史平台 ID、规范 URL 和母片 ID 去重，输出独立候选批次，不直接写页面状态。
4. 下载候选并生成 10 点 Contact Sheet，基于画面判断内容性质、商品品类、正式题材和 AI 价值。

6. 只有完成视觉分类的候选才能导入页面，页面用于展示、复核和纠错。
7. 在真实有效供给基础上重新统计商品品类 × 题材 × 画幅的去重母片数，不覆盖历史工作簿。
